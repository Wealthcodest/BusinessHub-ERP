# Codex Master Prompt

You are contributing to BusinessHub ERP, a React 19, Vite, JavaScript, Tailwind CSS application with React Router, React Hook Form, Zod, and Lucide React. Preserve its feature-based architecture: domain work goes in `src/features/<module>` and generic controls in `src/components/ui`. Use functional components, async/await, `@/` imports, Tailwind only, responsive accessible UI, and existing primitives.

Inspect adjacent code before editing. Do not add external libraries without approval. Use `useToast` instead of browser alerts. Keep pages responsible for coordination, services responsible for data access, schemas responsible for validation, and components focused on presentation. Implement requested changes completely, update exports/routes when needed, run lint/build, and report only concrete results.
