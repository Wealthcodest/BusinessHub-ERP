# Product Roadmap

## Current foundation

React application shell, dashboard, Business CRUD with local persistence, Zod-based form validation, shared UI primitives, routing, and toast notifications are available.

## Next milestones

1. Customer module and shared data-table conventions.
2. Laravel API, MySQL schema, authentication, and migration from local storage.
3. Inventory and invoicing workflows.
4. Accounting engine and financial reports.
5. Roles, audit trail, exports, integrations, mobile strategy, and production operations.

Priorities may change based on customer validation, compliance obligations, and delivery capacity.
