# Future Features

Planned capabilities include role-based access control, multi-business switching, audit logs, document attachments, notifications, approval flows, payment integrations, tax localization, currency conversion, import/export, dashboards, scheduled reporting, API/webhooks, and mobile clients.

Evaluate features with a product brief covering target user, workflow, data ownership, permissions, reporting impact, accounting impact, integration requirements, and acceptance criteria. Do not introduce a UI-only feature that implies a data guarantee the backend cannot provide.
